Resumen ejecutivo

Se scrapearon vía API GHL las 17.265 conversaciones de los últimos 90 días en la subaccount de Escollanos. Filtrando por conversaciones con asesor humano asignado + diálogo real de ≥3 turnos por lado quedaron 4.503 elegibles. De ahí se muestreó estratificado por producto × outcome (ganada / no-ganada) para 250 conversaciones, de las cuales 216 cumplieron el corte de diálogo válido.

Cada transcript se procesó para extraer texto literal de los asesores. Los 8 productos top se destilaron en patrones individuales y se consolidaron en este documento. Todos los textos son literales: copy-paste de los asesores reales con dos o tres variantes cuando difieren. Los precios se parametrizaron como [VARIABLE: precio_X] para leer de Custom Values vigentes y no quedar hardcoded.

Metodología

Pasada 1 · Metadata

Paginación API /conversations/search ordenada por last_message_date desc. Se capturaron ID, contactId, tags, asesor, dirección último mensaje, action automated/manual.

Pasada 2 · Transcripts

Por cada conversación muestreada, /conversations/{id}/messages con limit 100. Mensajes ordenados ascendente y exportados a Markdown con metadata + diálogo CLIENTE/ASESOR.

Estratificación

8 productos top × outcome (20 ganadas + 10 no-ganadas por producto) + 10 casos otros. Total objetivo 250, finales 216 tras filtrar diálogos cortos.

Destilación

Un agente especializado por producto leyó sus ~25 transcripts y extrajo: saludo, pitch, objeciones, cierre, follow-up, FAQs sugeridas, tono y léxico. Un agente consolidador generó KB maestra + CBRs.

02

Política de pago bifurcada por ciudad

  • Quito / Guayaquil / Cuenca: contraentrega · solo efectivo · De Una · transferencia Pichincha→Pichincha · link de pagos. NUNCA tarjeta en entrega.
  • Resto del país: previa cancelación obligatoria + Servientrega 24-48h con guía de rastreo.

El bot debe preguntar ciudad ANTES de cerrar para elegir el flujo correcto.

03

Postura clínica oficial

Universal: "NO tiene contraindicaciones". Para hipertensión, adulto mayor, medicación crónica, edad avanzada: siempre "100% natural, sin contraindicaciones, lo puede tomar con tranquilidad".

Única excepción: Embarazo / lactancia para Jarabe de Caléndula → derivar a médico.
